# Mapa zajímavých míst

Autor: Ondřej Mrkos
Škola: SPŠE Ječná – obor Informační technologie

---

## Popis projektu

Tento projekt je webová aplikace, která umožňuje ukládat a zobrazovat zajímavá místa na mapě.
Uživatel může přidat nové místo, přidat k němu název a popisek a ostatní uživatelé mohou vyhledat zajímavá místa v okolí své aktuální polohy.

---

## Funkce aplikace

* zobrazení mapy
* přidávání nových míst
* mazání míst
* vyhledávání míst v okolí
* využití geolokace

---

## Použité technologie

* PHP
* JavaScript
* Leaflet.js
* SQLite
* HTML
* CSS

---

## Spuštění aplikace

1. otevřete terminál ve složce projektu
2. spusťte PHP server:

```
php -S localhost:8000
```

3. otevřete aplikaci v prohlížeči:

```
http://localhost:8000
```
